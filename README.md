# Innovation & Patents Showcase I developed during my COOP
## Project Overview
A web-based page developed to showcase innovations and patents at Aramco, highlighting the achievements and contributions of inventors through an engaging and informative digital experience.
The page was designed to recognize innovation, present key achievements, and provide visitors with an organized way to explore featured inventions and innovators.

## Key Features
- Visual presentation of innovations and patents.
- Recognition of inventors and their achievements.
- Organized and user-friendly webpage layout.
- Interactive elements for an engaging browsing experience.

## Technologies Used
- HTML
- CSS
- JavaScript
